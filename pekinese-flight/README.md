# 🐶 Рыжий пекинес: летающие приключения

HTML5-игра для [Яндекс.Игр](https://yandex.ru/games) в стиле «летающей птички» (Flappy Bird).
Главный герой — рыжий пекинес, который летит через квартиру хозяйки, уворачиваясь от предметов домашнего интерьера. В конце каждого уровня его ждёт косточка и прыжок в руки к хозяйке.

## Возможности

- 5 уровней нарастающей сложности: «Уютная гостиная», «В прихожей», «Кухня и столовая», «Ванная комната», «Весь дом».
- Препятствия — элементы интерьера: диван, кресло, стул, ботинок, пушистый тапок, унитаз.
- Финальная сцена уровня: пекинес забирает косточку и запрыгивает на руки к хозяйке.
- Поддержка ПК (Пробел / W / ↑, левая и правая кнопки мыши, Esc для паузы) и мобильных (тап по экрану).
- Адаптивный полноэкранный canvas, сохранение прогресса и рекорда в `localStorage`.
- Интеграция Yandex Games SDK: `YaGames.init()` + `LoadingAPI.ready()`, полноэкранная реклама между уровнями, пауза звука при сворачивании вкладки.
- Все спрайты рисуются процедурно через Canvas 2D — в игре нет внешних графических файлов.

## Управление

| Действие        | Клавиши / жесты                                |
| --------------- | ---------------------------------------------- |
| Полёт вверх     | `Space`, `W`, `↑`, ЛКМ, ПКМ, тап по экрану     |
| Пауза           | `P`, `Esc`, кнопка II                          |
| Подтвердить     | `Enter`                                        |

## Локальный запуск

```bash
cd pekinese-flight
python3 -m http.server 8000
# открыть http://localhost:8000
```

Скрипт `/sdk.js` подставляется платформой Яндекс.Игр автоматически: локально он
вернёт 404, это нормально — игра корректно работает без SDK.

## Сборка для загрузки в Яндекс.Игры

Яндекс принимает игры как `.zip` с `index.html` в корне архива:

```bash
cd pekinese-flight
zip -r pekinese-flight.zip index.html style.css game.js sprites.js levels.js
```

Затем загрузите архив `pekinese-flight.zip` в [консоль разработчика Яндекс.Игр](https://yandex.ru/dev/games/console).

## Структура

```
pekinese-flight/
├── index.html    # разметка + подключение SDK
├── style.css     # стили UI и экранов
├── game.js       # состояние, физика, игровой цикл, SDK
├── sprites.js    # процедурная отрисовка пекинеса, хозяйки, препятствий
├── levels.js     # конфигурация уровней
└── README.md
```

## Технические заметки

- Canvas 2D, без внешних зависимостей.
- Пекинес описывается как круг радиуса `PEKINESE_COL_R` — честные коллизии без углов.
- Физика: гравитация + импульс прыжка, плавное вращение при падении / взлёте.
- Виртуальное разрешение по высоте 600 px масштабируется под любой экран.
- Все препятствия и декор — процедурная графика (Canvas API).
