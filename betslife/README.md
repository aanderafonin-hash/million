# 🎲 WorldPari — ставки на жизнь

> Раньше назывался BetLife. Бренд переименован, но в коде ещё встречаются исторические идентификаторы (`betslife/`, `betslife.token` в localStorage, `betslife-backend` на Fly.io) — они оставлены для обратной совместимости со старыми клиентами.

Мини-сайт в стиле букмекерской конторы, но с фишкой: основные «рынки» — случайные события из обычной жизни. Будет ли завтра дождь? Скинет ли кот кружку? Опоздает ли Вася на работу? Всё это можно собрать в купон, поставить виртуальные рубли и посмотреть, что «случилось».

Фронт — на чистом HTML/CSS/JS, без сборки. Весь прогресс (баланс, история, свои события) сохраняется в `localStorage`.

## Возможности

- Букмекерский тёмный UI: шапка с балансом, вкладки категорий, карточки событий с коэффициентами, купон справа.
- 6 категорий + история: 🎭 Жизнь, ⚽ Спорт, 🌀 Абсурд, 💼 Офис, 🏠 Дома, 🧑‍🎨 Мои, 📜 История.
- Экспресс-купон: несколько исходов перемножают коэффициенты.
- Симуляция исходов по истинным вероятностям (коэффициенты считаются с учётом маржи ~5%).
- Создание своих событий: заголовок, исходы и вероятности.
- Начальный баланс — 10 000 ₽, минимальная ставка — 10 ₽. Кнопка сброса всего прогресса.

## Запуск локально

```bash
cd betslife
python3 -m http.server 8000
# затем открыть http://localhost:8000
```

Или просто открыть `index.html` напрямую в браузере.

## Структура

```
betslife/
├── index.html   # разметка, модалки, купон
├── style.css    # тёмная букмекерская тема
├── events.js    # каталог событий по умолчанию
├── app.js       # рендер, купон, ставки, LocalStorage
└── README.md
```
