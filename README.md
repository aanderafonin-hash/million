# 🐕 Такса и косточки (Taksa & Bones)

HTML5-игра в стиле «змейки» для платформы [Яндекс.Игры](https://yandex.ru/games/).
Вместо змейки — милая такса с щенячьими глазками, которая гоняется за косточками.
С каждой съеденной косточкой такса становится длиннее.

## Возможности

- **30 уровней** с нарастающей сложностью — препятствия-квадратики от одиночных блоков до сложных лабиринтов.
- **Система наград**: 6 уровней отличия (бронза → серебро → золото → бриллиант → радуга → звезда) + звание за каждый уровень (Щенок → Юный охотник → Мастер раскопок → Легенда такс → Чемпион).
- **Рейтинг игроков** (топ-10) — локально на устройстве, с выделением текущего игрока.
- **Милая такса**: классический чепрачный окрас, большие щенячьи глаза с несколькими бликами и ресничками, розовые щёчки, высунутый язычок, моргание, прыгающая походка, виляющий хвост с линиями движения, розовые подушечки лапок.
- **Сердечки-искорки** вылетают при поедании косточки.
- Сохранение прогресса, имени игрока, открытых уровней и рейтинга в `localStorage`.

## Управление

| Действие      | Клавиши / жесты                |
| ------------- | ------------------------------ |
| Движение      | Стрелки, WASD                  |
| Пауза         | `Space`, `P`, кнопка II        |
| На телефоне   | Свайпы по холсту               |

## Запуск локально

Откройте `index.html` в любом современном браузере либо поднимите локальный сервер:

```bash
python3 -m http.server 8000
# затем открыть http://localhost:8000
```

Для полноценной работы Yandex Games SDK игру нужно тестировать из личного кабинета разработчика Яндекс.Игр — скрипт `/sdk.js` подставляется платформой автоматически при публикации.

## Сборка для загрузки в Яндекс.Игры

Яндекс принимает игры как `.zip` с `index.html` в корне архива.

```bash
zip -r taksa.zip index.html style.css game.js levels.js
```

Затем загрузите полученный `taksa.zip` в консоль разработчика Яндекс.Игр.


## Особенности

- Canvas 2D, без внешних зависимостей.
- Такса отрисовывается процедурно, все анимации — через Canvas API.
- Прогресс и рейтинг в `localStorage`.
- Поддержка мобильных устройств (свайпы) и клавиатуры (русская/английская раскладки).
- Вызов `sdk.features.LoadingAPI.ready()` после инициализации SDK — требование Яндекс.Игр.
