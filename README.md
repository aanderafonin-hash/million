# 🐕 Такса и косточки (Taksa & Bones)

HTML5-игра в стиле «змейки» для платформы [Яндекс.Игры](https://yandex.ru/games/).
Вместо змейки — такса, которая гоняется за косточками. С каждой съеденной косточкой такса становится длиннее.

## Управление

| Действие      | Клавиши / жесты                |
| ------------- | ------------------------------ |
| Движение      | Стрелки, WASD                  |
| Пауза         | `Space`, `P`, кнопка II        |
| На телефоне   | Свайпы по холсту               |

## Запуск локально

Откройте `index.html` в любом современном браузере либо поднимите локальный сервер:

```bash
python3 -m http.server 8000
# затем открыть http://localhost:8000
```

Для полноценной работы Yandex Games SDK игру нужно тестировать из личного кабинета разработчика Яндекс.Игр — скрипт `/sdk.js` подставляется платформой автоматически при публикации.

## Сборка для загрузки в Яндекс.Игры

Яндекс принимает игры как `.zip` c `index.html` в корне архива.

```bash
zip -r taksa.zip index.html style.css game.js
```

Затем загрузите полученный `taksa.zip` в консоль разработчика Яндекс.Игр.

## Особенности

- Canvas 2D, без внешних зависимостей.
- Такса отрисовывается процедурно (голова с висячими ушами, длинное тело, лапки, хвост) — нет внешних картинок, архив лёгкий.
- Сохранение рекорда в `localStorage`.
- Плавное ускорение по мере роста счёта.
- Поддержка мобильных устройств (свайпы) и клавиатуры (русская/английская раскладки).
- Вызов `sdk.features.LoadingAPI.ready()` после инициализации SDK — требование Яндекс.Игр.
